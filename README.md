# Список покупок — React + Node.js

Простое домашнее задание. Можно добавлять и удалять товары, а общая стоимость считается автоматически.

## Запуск

1. Установите Node.js (если он ещё не установлен).
2. Откройте терминал в папке проекта.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте адрес из терминала (обычно http://localhost:5173/).

## Что используется

- `src/App.jsx` — главный компонент, `useState`, добавление и удаление товаров, общая сумма.
- `src/ShoppingItem.jsx` — отдельный компонент товара с `props`.
- `src/App.css` — оформление.

Node.js используется для запуска Vite; отдельный сервер не нужен.
